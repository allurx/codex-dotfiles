# codex-dotfiles

个人 Codex 全局协作指令的私有版本仓库。

## 文件与作用域

- `codex/AGENTS.md`：全局指令的唯一维护源。
- 本机生效文件：Codex 主目录中的 `AGENTS.md`；默认是 `%USERPROFILE%\.codex\AGENTS.md`，设置了 `CODEX_HOME` 时以该目录为准。
- 只管理明确纳入版本控制的配置文件，不复制或同步整个 Codex 主目录。凭据、会话、记忆、日志、缓存和部署备份均不入库。

## 修改与发布流程

1. AI 在本仓库中修改 `codex/AGENTS.md`，检查规则冲突、重复和变更范围；此时不替换本机文件，不提交或推送。
2. 用户查看 diff，提出调整意见或确认待部署版本。
3. 获得部署授权后，核对本机目标及 `AGENTS.override.md` 覆盖关系，创建时间戳备份，用用户确认的仓库版本替换本机文件，再重新读取并核对内容一致。若文件在审查后又发生变化，先核对差异，不能覆盖未经处理的修改。
4. 按用户明确授权提交并推送到远程仓库。一次“确认，替换本机文件并提交推送”可以授权连续完成这些步骤。

Git 提交和推送不会自动替换本机文件。流程由 AI 执行和验证，不维护额外的部署脚本。

## 验证与恢复

- 修改前检查工作区状态；提交前审查 staged diff，并运行 `git diff --cached --check`。
- 部署后比较仓库源文件与本机文件的内容，在新 Codex run 或任务中验证加载。旧任务中重新读取只能证明文件已保存。
- Git 历史保留已提交版本，本机时间戳备份保留替换前的状态。恢复或重新部署旧版本前，仍需用户授权并核对准确目标，保留已有修改。
- 项目特有约束保留在对应项目中，可复用的长流程放入 Skill；此仓库中的全局文件只保存跨项目的长期规则。

加载机制参考：[官方 AGENTS.md 文档](https://learn.chatgpt.com/zh-Hans/docs/agent-configuration/agents-md)。
